# Family Business Pending Confirmed Decisions

## Purpose

This file contains **only** decisions that:

1. were explicitly confirmed by the project owner; and
2. have not yet been synchronized to the canonical Google Docs GDD.

It is not:

- an open-question list;
- a backlog;
- a design idea list;
- a place to store implementation guesses;
- a replacement for the GDD Decision Register.

## Current Decisions

**None.**

The previously recorded static Business visual decision has been synchronized to the canonical GDD and is no longer pending.

Open decisions such as Economy Index growth/cadence, House level visuals, Relationship Event content values, advertising, localization, etc. remain in the GDD Decision Register and must **not** be copied here as confirmed pending decisions.

## Maintenance Rule

When a newly confirmed decision has not yet reached the GDD, record it here with:

```text
title
confirmed date
affected systems
exact confirmed decision
GDD section requiring synchronization
status: pending
```

Remove the entry immediately after the GDD is synchronized.
